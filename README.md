Учебная работа по анализу данных в задачах информационной безопасности.

## Цель

Исследовать события авторизации и подготовить постановку задачи для будущей модели, которая будет **отмечать потенциально подозрительные попытки входа** для проверки специалистом ИБ.

- **Бизнес-задача:** снизить объём ручной проверки журналов и быстрее замечать подозрительные авторизации.
- **ML-задача:** бинарная классификация событий (0 — обычное, 1 — подозрительное).
- **Основная предлагаемая метрика:** F2-score. Она придаёт больший вес Recall (полноте обнаружения), но также учитывает Precision (точность тревог).

**На этом этапе модель не обучается.** Выполнен разведочный анализ данных (EDA), а метрики выбраны для будущей оценки модели.

## Данные

Файл `auth_events.csv` содержит 2400 **синтетических**, а не реальных событий. Они сгенерированы скриптом `generate_data.py` (фиксированное зерно генератора `seed=42`). Метки `is_suspicious` также искусственные. Их нельзя трактовать как подтверждённые случаи атак.

| Поле | Значение |
| --- | --- |
| `event_id` | Идентификатор события |
| `hour` | Час попытки входа (0–23) |
| `failed_attempts_24h` | Число ошибочных вводов пароля за последние сутки |
| `new_device` | Новое устройство (0/1) |
| `unusual_country` | Непривычная страна (0/1, возможны пропуски) |
| `vpn_used` | Использование VPN (0/1) |
| `is_suspicious` | Учебная целевая метка (0/1) |

## Что выполнено

1. Бизнес- и ML-постановки задачи.
2. Выбор и обоснование метрик качества (F2, Precision, Recall, PR-AUC).
3. EDA: статистики, типы данных, пропуски, распределение классов, ошибки входа, время входа, новые устройства, непривычная страна, корреляции.
4. Графики с помощью `matplotlib` и `seaborn` и выводы о дальнейшей предобработке.

## Содержимое репозитория

- `Задание_1_EDA_Авторизации.ipynb` — код анализа, диаграммы и комментарии.
- `auth_events.csv` — набор учебных данных.
- `generate_data.py` — исходный генератор данных.
- `Задание_1_Отчет_EDA.docx` — отчёт в Word.

## Запуск

Требуется установленный Python 3.

```bash
python -m pip install -r requirements.txt
python -m notebook
```

В открывшемся браузере выберите `Задание_1_EDA_Авторизации.ipynb` и запустите ячейки сверху вниз (`Run All`). Файл `auth_events.csv` должен лежать рядом с Notebook.

Для повторного создания CSV можно выполнить:

```bash
python generate_data.py
```

## Ограничения

Данные демонстрационные: обнаруженные закономерности определяются процедурой синтетической генерации и **не доказывают** качество детектора в реальной информационной системе. Подозрительная авторизация не обязательно является попыткой взлома или кражи данных.
